# Brick Reviews

A course and professor review platform for RIT students. Reviews come only from students with a verified @rit.edu email, and each student can review a course once.

*Not affiliated with, endorsed by, or sponsored by RIT.*

## Features (planned)

- Sign up and verify your account with an @rit.edu email
- Search for courses and professors
- Read reviews and average ratings, no account needed
- Write, edit, and delete your own reviews (shown anonymously)
- Report inappropriate reviews for admin moderation

## Tech Stack

- **Frontend:** Angular, TypeScript
- **Backend:** Java, Spring Boot, Spring Security
- **Database:** PostgreSQL, Flyway
- **Tooling:** Docker, GitHub Actions
